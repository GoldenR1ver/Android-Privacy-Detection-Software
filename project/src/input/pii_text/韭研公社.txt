韭研公社隐私协议
版本号：第二版
生效时间：2022年6月1日

韭研公社承诺将尽全力保障您的个人隐私，在您使用韭研公社网站和app的过程中，韭研公社将按照本隐私协议处理您的个人信息。请您在向韭研公社提交个人信息之前，充分阅读、了解本协议。您继续使用我们（指韭研公社网站和app的经营者上海韭研信息科技有限公司及现有和/或将来设立的相关关联公司的单称或合称）的产品，即意味着同意我们按照本协议收集、使用、储存、共享、转让和公开披露您的相关信息。有关您个人信息权益的重要条款已用加粗形式提示，请您特别关注。随着网站和app版本的迭代更新，韭研公社未来可能根据信息处理的需要，不定期更新或修改本协议。如果对本隐私政策有任何疑问，您可以通过我们在本隐私政策中公布的联系方式与我们联系。

我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们致力于维持您对我们的信任，恪守以下原则，保护您的个人信息：权责一致原则、目的明确原则、选择同意原则、最少够用原则、确保安全原则、主体参与原则、公开透明原则等。同时，我们承诺，我们将按照业界成熟的安全标准，采取相应的安全保护措施来保护您的个人信息。

一、我们搜集信息的目的
我们所搜集的信息中，相当部分是无特殊目的，而由您使用过程中自动产生系统依法保存的日志信息，此外部分信息在我们搜集后可能被用于韭研公社产品的特殊目的：
1、为了满足合规性要求。
2、为您提供更好的服务。
3、进行全站内部数据分析研究，以改善产品功能，帮助我们设计新服务，提升现有服务体验。
4、确保我们服务的安全性，如用于身份验证、客户反馈、安全防范、诈骗监测、存档和备份用途等。

二、我们如何收集和使用您的个人信息
我们收集的信息，来自您在注册和使用我们服务过程中提交和产生的信息，也包括一些其他类别信息，我们尽量确保不收集与韭研公社提供的服务无关的个人信息。我们的收集包括但不限于如下类别：
1、注册信息。您注册账号时需要向我们提供以下信息：用户名、手机号码、密码等。在您注册韭研公社帐号时，我们会使用手机号码对您进行实名验证，如您拒绝提供手机号码验证，您仅可使用我们的部分服务。
2、详情资料信息。当您使用韭研公社过程中，为了更好的在社区互动，您可能进一步上传头像、填写个人说明、选择地域和投资风格等信息，如果您拒绝填写，可能影响社区的互动体验。
3、搜索关键词信息。当您使用韭研公社提供的搜索服务时，我们会收集您的查询关键字信息、设备信息等，为了提供高效的搜索服务，这些信息有部分会暂时存储在您的本地存储设备之中。
4、草稿信息。当您使用韭研公社编辑文本却中途暂停时，为了使您的个人编辑内容不因违背您意愿的意外情况而丢失，我们可能会将部分文本信息暂时存储在您的本地存储设备之中。
5、真实身份信息。当您使用韭研公社提供的身份认证服务（若有）时，我们会收集您的姓名、身份证号、有关身份证明等信息。如果您不提供这些信息，我们将无法提供相关服务。
6、联系方式信息。当您向韭研公社进行帐号申诉或其他联系时，为了方便与您联系或帮助您解决问题，我们会收集并记录您的姓名、手机号码、电子邮件及其他联系方式等个人信息。如您拒绝提供上述信息，我们可能无法向您及时反馈投诉结果。
7、我们可能从第三方获取您个人信息的情形，例如通过微信登录韭研公社。我们通过第三方获取信息需要经由您的授权和第三方平台的制度许可，可能获取第三方的公开信息（包括但不限于昵称、头像以及第三方按照其授权规则向我们提供的其他信息）用以记录您的登陆状态。
8、Cookie信息。您使用我们的服务时，韭研公社会在您的计算机或移动设备上存储名为 Cookie 的小数据文件。我们使用该等信息判断注册用户是否已经登录，提升服务/产品质量及优化用户体验。您可根据自己的偏好管理或删除Cookie，如您不希望个人信息保存在 Cookie 中，您可根据浏览器的功能进行相应调整。
9、设备权限调用。韭研公社在提供服务的过程中，可能需要您开通一些设备权限，例如通知、相册、相机、手机通讯录、蓝牙等访问权限。您也可以在设备的设置功能中随时选择关闭部分或者全部权限，从而拒绝韭研公社收集相应的个人信息。
10、唯一设备标识信息。韭研公社将在提供服务的过程中，收集您的设备IMEI、IMSI、设备MAC地址、软件列表、设备序列号、android ID等用户信息，但频率不超过1次/分钟。设备处于后台运行状态下亦会获取您的MAC信息。
11、我们可能使用您提交的个人通讯方式，通过网站私信、弹窗、短信、推送或其他方式向您推广或介绍我们的产品服务。
12、读取外部存储。韭研公社在提供服务的过程中，需要访问您设备的存储图片以便更好地发帖，您也可以在设备的设置功能中随时选择关闭这部分权限。
13、写入外部存储。韭研公社在提供服务的过程中，需要获取您设备的写入存储权限以便您更好地保存文档、图片等，您也可以在设备的设置功能中随时选择关闭这部分权限。
14、为识别您的设备ID并预防恶意程序及反作弊、提高服务安全性、保障运营质量及效率，我们会收集您的设备信息（包括IMEI、MEID、Android ID、IMSI、GUID、MAC地址）、您安装的应用信息或运行中的进程信息。
15、为对应用错误异常进行监控，以及对平台进行优化升级，我们将收集应用软件运行异常信息。
16、为实现运行故障报错及分析和解决您在使用韭研公社过程中所遇到的问题，我们将收集您的设备信息（GUID、MAC地址）、浏览和操作记录。
17、为了在应用使用过程中防止欺诈及保护您的交易安全，我们将收集您的设备位置信息。
18、其他法律法规允许获得的信息，以及涉及违法犯罪等法律强制而无需征得您同意的信息。

上述中的部分信息，单独存在时可能无法识别您的个人身份，因而或不涉及您的隐私信息。但当这些信息与您的其他信息互有联系并可以识别您的个人身份时，则在这些信息结合使用期间，我们会将上述信息作为您的个人隐私信息，按照本协议对其进行处理与保护。特别的说明，您公开发表在社区的内容，包括帖子和评论，均不属于个人隐私范畴。

三、我们如何管理和保护您的个人信息
1、您可以根据您的需要，增删、调整或修改提交给韭研公社的相关信息；我们将采取适当的技术手段，保证收集到的有关于您的个人信息的准确性和及时性。
2、您有权注销您的韭研公社账号。您可以通过我们的在线客服@韭菜团子，与我们取得联系，我们将在5个工作日内为您提供账号注销服务，在您主动注销账号之后，我们将停止为您提供服务，并根据中国法律的规定删除您的个人信息，法律另有规定的除外。
3、韭研公社将竭尽所能确保您的信息安全。我们采取互联网业内标准做法来保护您的个人信息，防止信息遭到未经授权访问、披露、使用、修改、损坏或丢失。
4、但请您理解，您接入我们的服务所用的系统和通讯网络，可能出现我们可控范围之外的风险，而且由于技术的限制以及可能存在的各种恶意手段，在互联网行业，不可能始终保证信息百分之百的安全。
5、在发生个人信息安全事件的场合，我们将按照法律法规的要求，及时向您告知：安全事件的基本情况和可能的影响、我们已采取或将要采取的处置措施、您可自主防范和降低风险的建议、对您的补救措施等。我们将及时将事件相关情况以短信、电话、推送通知等方式告知您，难以逐一告知个人信息主体时，我们会采取合理、有效的方式发布公告。同时，我们还将按照监管部门要求，主动上报个人信息安全事件的处置情况。
6、我们的信息均保存在中国境内；我们仅会在达到本协议所述目的所必需的时限内保存您的个人信息，法律法规要求的其他情形除外。

四、与第三方相关的信息处理
1、在韭研公社的网站中，存在网友上传共享的第三方网站链接，对此类第三方链接韭研公社无控制权。您在访问第三方链接时，请根据自己的情况，选择适当的方式在第三方网页保护您的个人隐私。
2、在未经您同意或授权的情况下，韭研公社不会将您的个人信息提供给无关第三方。
3、在本协议的使用目的范围内，韭研公社可能会将您的个人信息与关联公司（若有）或授权合作伙伴共享。但我们只会在本协议使用目的范围内共享，且只共享必要的信息，并签署严格的保密协议，否则将再次征求您的授权同意。
4、在未经您同意或授权的情况下，韭研公社不会将您的个人信息转让给任何公司、组织和个人，韭研公社被收购的情况除外，但依然遵循在本协议的使用目的范围内。
5、为提供服务之目的，韭研公社将与第三方共享您的信息或韭研公社委托的第三方或嵌入的第三方代码、插件、SDK（详见下方附件，第三方SDK清单）等将根据其隐私政策收集和使用您的信息。您同意我们和第三方在符合法律法规的前提下可将收集的信息用于其他服务和用途。
6、在任何情况下，韭研公社均不会出于经济利益，泄露或转让您的个人隐私信息。
7、基于法律法规、法律程序、诉讼或政府主管部门强制性要求的情形除外。但在符合法律法规的前提下，当我们收到上述披露信息的请求时，我们会要求必须出具与之相应的法律文件。

信息保护： 我们承诺保护您的个人信息安全。在您使用 "Matisse - 图片选择SDK" 过程中，我们仅会访问您的相册以显示您选择的图片，不会将您的图片内容上传至我们的服务器或第三方。

自启动和关联启动说明：
为确保本应用处于关闭或后台运行状态下可正常接收到客广端推送的广播信息，本应用须使用(自启动)能力，将存在一定频率通过系统发送广播唤醒本应用自启动或关联启动行为，是因实现功能及服务所必要的。

com.alipay(支付宝;mPaaS;阿里芝麻信用实名认证;芝麻认证)：
我们的应用集成了一些第三方SDK，其中包括com.alipay(支付宝;mPaaS;阿里芝麻信用实名认证;芝麻认证)等。这些SDK的集成是为了提供以下功能和服务：
支付宝：用于进行支付功能，需要获取您的支付信息和授权进行支付操作。

com.alipay.share
SDK 描述：支付宝分享 SDK
使用目的：在开屏广告页提供「分享到支付宝」按钮，方便用户将广告内容一键分享至支付宝生活号或好友会话，提升广告传播效率。

com.qq.e
SDK 描述：优量汇 Android SDK（腾讯广告联盟）
使用目的：请求并展示腾讯联盟开屏广告，完成曝光、点击归因及效果转化回传。

com.umeng.umverify
SDK 描述：友盟+智能认证 SDK
使用目的：在开屏广告场景下，通过运营商网关取号能力实现「一键登录」，减少用户等待时间，提高广告跳转转化率。

SDK 描述：Suyi 聚合广告 SDK
使用目的：聚合多家广告平台（含优量汇、穿山甲、快手等），自动优选出 eCPM 最高的开屏广告进行展示，提升广告收益。

SDK 描述：友盟+移动统计 SDK
使用目的：统计开屏广告的展示、点击、转化事件，生成广告效果报表，用于后续流量分层与广告策略优化。

SDK 描述：天目 Ads SDK
使用目的：作为补充广告源，向用户投放天目平台提供的开屏广告，增加广告填充率。

com.umeng.socialize
SDK 描述：友盟+社会化分享 SDK
使用目的：在开屏广告落地页提供多平台（微信、QQ、微博等）分享组件，方便用户转发广告内容，扩大品牌曝光。

com.hihonor.push
SDK 描述：荣耀推送 SDK
使用目的：当用户点击开屏广告并在落地页完成关键事件（如预约、下载）后，通过荣耀系统级推送通道回传结果通知，确保转化数据不丢失。

com.bytedance.gromore
SDK 描述：穿山甲融合 SDK Android 版
使用目的：聚合穿山甲及其联盟广告源，智能竞价并渲染开屏广告，同时完成点击监测与深度链接跳转。

mPaaS：用于提供移动应用开发和运营的全周期服务，需要获取您的设备信息和应用使用情况以优化应用性能和体验。
阿里芝麻信用实名认证：用于进行实名认证服务，需要获取您的个人身份信息以验证您的身份。
