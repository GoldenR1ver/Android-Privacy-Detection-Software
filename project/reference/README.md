# reference — 设计文档与参考资料

本目录保存项目的设计、验收标准、法律参考和汇报材料。**修改代码前建议先读这里的设计边界。**

## 1. 文档

| 文件 | 内容 |
| --- | --- |
| `开发计划.md` | 阶段目标、验收标准、风险与回退策略、当前完成度诊断 |
| `plan.md` | 补充设计说明 |
| `程序管线.md` | 早期 src 管线结构（部分内容已被当前实现替代） |
| `阶段0到阶段1衔接说明.md` | 旧标签 → 新 schema 的桥接 |
| `lab4_requirements_extracted.txt` | 课程要求摘录 |
| `支付宝页面小程序与自动化失败说明.md` | 具体 App 的自动化限制案例 |
| `系统设计Lab4.pptx` | 系统设计汇报 |
| `法律参考文件/` | PIPL / CCPA / GDPR PDF 与分类原则 |

## 2. 法律参考

`法律参考文件/README.md` 说明：

- 个人信息矩阵的分类原则；
- 哪些条目可以进入 `privacy_knowledgebase/input.md`；
- 如何避免擅自添加法规未列敏感项。

修改知识库前请先读该说明。

## 3. 汇报材料

`验收汇报ppt/` 与 `../ppt/` 下的幻灯片/图表用于课堂汇报。图表脚本在 `../ppt/generate_*.py`，数据来源是 `src/output/` 的审计报告。

## 4. 与代码的关系

- `开发计划.md` 描述「为什么这样设计」，当前实现以 `src/` 为准；
- `程序管线.md` 是早期版本，命令与目录可能已过时；
- 法律矩阵的机器可读版本由 `privacy_knowledgebase/build_kb.py` 生成，不要直接手改 `knowledge_base/*.json`。
