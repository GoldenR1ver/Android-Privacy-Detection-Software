## 推荐执行顺序

1. 先把旧标注转为新 claim：
```bash
python -m privacy_audit.cli bridge-stage1 \
  --review-bundle-file "..\\oldsrc\\analyzer\\data\\main\\review_bundle.json" \
  --output-file "output\\stage1\\claims_from_review_bundle.json"
```

2. 再跑 Lab4-1（规则引擎）：
```bash
python -m privacy_audit.cli lab4-1 \
  --app-name Keep \
  --policy-file "input\\policies\\Keep.txt" \
  --evidence-file "input\\evidence\\Keep.json" \
  --rules-file "privacy_audit\\rules\\decision_rules.yaml"
```

3. 阶段1收尾（unknown labels 自动聚类 + 半自动扩充映射）：
```bash
python -m privacy_audit.cli refine-stage1-mapping \
  --bridge-output-file "output\\stage1\\claims_from_review_bundle_baseline.json" \
  --mapping-file "privacy_audit\\config\\legacy_label_mapping.yaml" \
  --clusters-output-file "output\\stage1\\unknown_label_clusters.json" \
  --suggestions-output-file "output\\stage1\\mapping_suggestions.json"
```

4. 近邻匹配增强（文本相似度，不依赖纯关键词）：
```bash
python -m privacy_audit.cli bridge-stage1 \
  --review-bundle-file "..\\oldsrc\\analyzer\\data\\main\\review_bundle.json" \
  --output-file "output\\stage1\\claims_from_review_bundle_round8_nn30.json" \
  --nn-threshold 0.30
```

本轮实测覆盖率：
- baseline：`55 / 200`（unknown `99`）
- refined：`120 / 200`（unknown `45`）
- nearest-neighbor：`143 / 200`（unknown `24`，`71.5%`）
